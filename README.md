# かたち パズル

3〜7歳向け・家庭用の型はめパズルです。iPad の Safari でホーム画面に追加すると、オフラインで動きます。
仕様は「かたちパズルアプリ 仕様書」にもとづいています。数直線すごろく（かずの すごろく）とは別のアプリです。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| index.html | 画面（タイトル・パズル・保護者画面・くるくるチェック・使い方） |
| style.css | 見た目 |
| app.js | 形の定義、問題づくり、ピースの動き、音声、記録、保護者画面 |
| manifest.json | ホーム画面追加用の設定 |
| sw.js | Service Worker（オフライン用キャッシュ） |
| audio/list.json | 録音音声のキー一覧（初期状態は空 = 合成音声） |
| icons/ | ホーム画面アイコン（180・192・512px） |

外部ライブラリ・CDN・Webフォントは使っていません。ビルドも不要です。

## 公開と iPad への入れ方

数直線すごろくと同じです。

1. GitHub で新しいリポジトリを作り（すごろくとは別）、このフォルダの中身をすべてアップロードする
2. Settings → Pages → Branch を `main` / `/(root)` にして Save
3. iPad の Safari で公開URLを開き、共有 →「ホーム画面に追加」
4. ホーム画面のアイコンから一度起動し、機内モードでも動くことを確かめる

保存データ（記録・設定）は、すごろくとは別に保存されます。

## 更新のしかた

ファイルを直したら `sw.js` の `VERSION` と `app.js` の `APP_VERSION` を上げてアップロードします。iPad はオンラインで起動したときに新しい版へ切り替わります。

## レベルと操作

| レベル | 名前 | 操作 |
| --- | --- | --- |
| 1 | おなじ かたち | 2つから、穴に合うピースをタップ |
| 2 | にている かたち | 似た形3つから、穴に合うピースをタップ |
| 3 | まわして いれる | ピースをタップして90度ずつ回し、向きが合ったら穴をタップ |
| 4 | 2つで つくる | 2〜3個のピースを回し（タップしたピースが選ばれる）、入れたい場所をタップ |
| 5 | あたまで まわす | 回さずに3つから選ぶ（正解を回したもの1つ＋裏返しを回したもの2つ） |

- まちがえたら、ピースが穴の上まで飛んで「合わない様子」を見せてから戻ります。×や減点はありません
- 2回まちがえると手助けが入ります（レベル1・2・5は正しいピースが光る、レベル3・4はピースが正しい向きまで回り、入れる場所が点滅する）
- 1回は8問。終わると、その回に作った形が並びます

## 音声

初期状態は iPad の日本語合成音声です。録音に差し替える場合は `audio/` に mp3 を置き、`audio/list.json` にキーを書きます。

| キー | 内容 |
| --- | --- |
| intro1 / intro3 / intro4 / intro5 | 各レベルの説明（各回の最初の2問だけ） |
| ok_＜形のキー＞ | 「ぴったり！ さんかく」など（形のキーは app.js の SHAPES） |
| pittari | ぴったり！（レベル5） |
| dekita_＜名前＞ | 「できた！ いえ」など（レベル4） |
| yokumite / koko / erande | 手助けの声 |
| yattane / mataashita | 1回の終わり |
| checkq / thanks | くるくるチェック |

## 実機で確かめたいこと

- [ ] レベル3・4で「回す→穴をタップ」の2段階の操作が4〜5歳に伝わるか（伝わりにくければ、説明の声やピースの回転マークを見直す）
- [ ] レベル4の拡大されたピース（iPad mini で一辺約200pt）がトレイに収まるか
- [ ] レベル5の形（正方形4〜5個の形）の見分けが6〜7歳にちょうどよい難しさか
- [ ] 1回8問の長さ（試算で約2〜4分）
